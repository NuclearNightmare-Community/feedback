# Security

Our mods run code on players' computers, and the installer adds files to the game folder. If you find a way they could harm a player, please tell us privately.

**Report it here:** [Report a vulnerability](https://github.com/NuclearNightmare-Community/feedback/security/advisories/new) (private; only the maintainers see it). Every NuclearNightmare-Community repo also has a "Report a vulnerability" button under its Security tab.

**What counts:** anything that could get an unsigned or altered file installed or run, a way for another player in a lobby to affect your computer through one of our mods, the installer writing outside the game folder, or anything that exposes your personal information.

**Not a security issue:** game bugs, cheats or exploits in the game itself (please report those to the game's developers), and normal bugs in our mods (use [a bug report](https://github.com/NuclearNightmare-Community/feedback/issues/new?template=bug.yml)).

**What happens next:** we'll get back to you as soon as we can, keep you posted while we work on a fix, and credit you when it ships, unless you'd rather not be named.

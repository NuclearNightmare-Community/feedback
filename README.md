# Feedback for Nuclear Nightmare community mods

Bug reports, ideas and questions for the mods published by **NuclearNightmare-Community**: Nucleus (Mod Core), Mod Manager, HUD Clock, Map Waypoints+, Whistle Emote Mute, and the installer and base pack.

- **Found a bug?** [Open a bug report](../../issues/new?template=bug.yml). Not sure which mod caused it? That's fine: pick "Not sure".
- **Have an idea?** [Suggest a mod or feature](../../issues/new?template=idea.yml).
- **A question, or something to show?** Use [Discussions](../../discussions).
- **A security problem** (for example a way to get a file past the installer's checks)? Please don't post it publicly: see [SECURITY.md](SECURITY.md).

This is an unofficial, community project, not affiliated with the game's developers. Problems with the game itself (without mods) belong with the developers.
